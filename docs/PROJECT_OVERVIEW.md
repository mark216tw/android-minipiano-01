# 專案說明

## 1. 產品定位

mini 鋼琴是一款「打開即可彈奏，能匯入樂譜並跟著聽」的離線 Android 電子琴。主介面使用鋼琴鍵盤與起音提示，不提供五線譜顯示。

適用情境：自由試彈、和弦與滑奏、錄製短演奏、聆聽 MusicXML 曲目、以聲部靜音搭配手動跟彈。

## 2. 目標

- 降低觸控至發聲路徑中的讀檔、解碼與 UI 等待。
- 提供可比較的真實採樣與輕量合成音色。
- 讓常見 MusicXML 音符、表情與演奏順序能離線播放。
- 保留原始演奏與原譜，匯出時再選擇量化或轉存。
- 提供高對比、可切換明暗與主題色的操作介面。

## 3. 目前範圍

| 領域 | 已實作 |
|---|---|
| 彈奏 | 多指、滑奏、和弦、音域、鍵寬、延音 |
| 音訊 | 64 發聲槽、立體聲串流、三種音色、響度補償、音量 |
| 錄製 | 音符及踏板事件、速度／拍號、倒數、節拍器 |
| 樂譜 | XML／MXL／JSON 包裝、力度、速度、反覆、跳轉、延音線 |
| 播放 | 共用播放／暫停圖示、停止、跳轉、倍率選單、聲部靜音、背景播放與媒體通知 |
| 匯出 | 原 XML 轉存、量化後建立演奏譜 |
| 外觀 | 全螢幕、系統／淺色／深色、六色與 Hue |
| 資料 | 多音譜保存、改名、刪除、上次選取還原、設定保存及舊錄製移轉 |

## 4. 執行環境

- Android 8.0 以上；目標 Android 16。
- Java 17 與原生 Android UI；音訊為 AudioTrack。
- 執行時不需要 NDK、第三方播放服務、帳號或網路。
- 聲音由素材或程式合成，不使用麥克風錄音。
- APK 約 36.17 MiB；實際容量依建置版本與資源變更而異。

## 5. 已知範圍限制

- 背景及鎖屏播放已加入框架測試，仍需真機驗收與耗電量測。
- 採樣只有一個力度層，不含循環及原音色庫的共鳴／放鍵噪音層。
- MusicXML 能力與簡化規則詳見 [支援文件](MUSICXML_SUPPORT.md)，不是完整記譜編輯器。
- 原譜轉存輸出主 XML；不重建 MXL 包與其他附帶資源。
- 尚未量測端到端真機延遲；不同裝置、喇叭與耳機可能有不同表現。
- 藍牙輸出通常有額外延遲，與 APP 音訊緩衝的優化分開評估。

## 6. 後續發展方向

以下為候選方向，並非已完成功能或承諾時程：

1. 建立真機矩陣，量測延遲、音訊中斷、耗電與溫度。
2. 依量測結果評估 C++／Oboe 輸出。
3. 增加多力度採樣、混響與音色細節。
4. 音譜庫搜尋／分類、A–B 段落循環與練習進度。
5. MIDI／WAV 匯出及更完整的樂譜記號。
