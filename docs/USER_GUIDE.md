# 使用指南

## 1. 安裝與第一次啟動

1. 依 [建置指南](BUILD_AND_TEST.md) 產生 `app-debug.apk`，再安裝至 Android 8.0 以上裝置。
2. 開啟 mini 鋼琴；主畫面預設為橫向、沉浸式全螢幕。
3. 首次啟動提供小星星示範曲。
4. 預設採樣音色在背景載入，進度會顯示於畫面上方；期間暫用合成鋼琴。

系統列隱藏時，可從邊緣滑動暫時叫出。設定頁會顯示系統列，返回主畫面後恢復全螢幕。較新 Android 的大螢幕裝置可能不遵循固定橫向要求。

## 2. 主畫面控制

| 控制 | 用途 |
|---|---|
| 匯入 | 透過系統檔案選擇器開啟樂譜 |
| 匯出 | 原譜轉存或演奏資料匯出 |
| 錄製 | 開始／結束目前演奏錄製 |
| 播放／暫停 | 自動演奏或暫停 |
| 停止 | 停止播放、歸零並清理發聲狀態 |
| 速度 | 循環選擇 0.5、0.75、1、1.25、1.5 倍 |
| 聲部 | 勾選要播放的聲部 |
| 匯入摘要 | 查看已處理功能與提示 |
| 進度條 | 依樂曲時間跳轉 |
| 錄製 BPM | 開啟設定，調整新錄製速度 |
| 音域 −／＋ | 以八度移動可見音域 |
| 鍵寬 | 切換 1／2／3 個八度的可見鍵盤 |
| 延音 | 切換手動延音踏板 |
| 右上角齒輪 | 進入完整設定頁 |

資訊列顯示目前樂曲 BPM、原譜小節與演奏次數；錄製設定的 BPM 和匯入曲目的速度是不同用途。

## 3. 手動彈奏

- 按下琴鍵即觸發聲音；多指可形成和弦。
- 按住音符，或在鍵盤上滑動進行滑奏。
- 手動琴鍵使用主題色；自動演奏使用黃色。
- 自動播放每次起音觸發約 140 ms 的閃亮、邊框與漣漪，同音連按也可辨識。
- 手動延音開啟時，放開琴鍵後仍可持續衰減，關閉踏板後釋放音符。

採樣音色有自然尾音上限，不會無限延長。一般觸控採固定力度，MusicXML 則依樂譜力度播放。

## 4. 匯入與自動播放

1. 按「匯入」，選擇 `.musicxml`、`.xml`、`.mxl` 或含 `musicxml` 字串的 JSON 包裝檔。
2. 等待解析及保存完成，查看匯入摘要。
3. 按「播放」，觀察亮鍵、小節位置及 BPM。
4. 視需要調整速度倍率、暫停、停止或拖動進度條。

例如副檔名是 `.musicxml`，內容卻是 JSON 的檔案，也會依實際內容擷取內層 XML。

匯入摘要的提示不一定代表失敗。例如「文字速度未自動解讀：ritard.」表示數值速度與音符可播放，但文字的漸慢幅度未猜測。完整規則請見 [MusicXML 支援](MUSICXML_SUPPORT.md)。

## 5. 聲部與跟彈

1. 播放曲目後按「聲部」。
2. 清單顯示樂器名稱、聲部號碼及譜表。
3. 勾選代表播放，取消勾選代表靜音。
4. 按「完成」關閉清單，繼續手動跟彈。

靜音只影響自動播放，不修改原譜或刪除音符；手動彈奏仍然發聲。設定會保存至目前曲目。聲部依 XML 身分辨識，不以音高強行判定左右手。

## 6. 錄製與回放

1. 在齒輪設定中選擇 BPM、拍號、倒數及節拍器。
2. 按「錄製」。若已有曲目，先確認取代提示。
3. 完成倒數後開始彈奏，踏板事件也會記錄。
4. 按「結束錄製」，再按「播放」檢查。
5. 匯出需要保留的內容。

原始時間與量化結果分開。APP 不使用麥克風；錄製內容是音符與操作事件，並非音訊檔。目前未提供 WAV 匯出。

## 7. 匯出

### 原譜轉存

適用於新版匯入曲目。直接輸出保存的內層 XML，保留版面、歌詞與記號。檔名預設含 `_原譜`。

JSON 會轉存其 `musicxml` 欄位；MXL 會輸出主 XML，不重新封裝壓縮檔或附帶資源。聲部靜音不改寫原譜。

### 演奏資料

選擇八分或十六分音符量化後，重新建立鋼琴樂譜。檔名預設含 `_演奏`。自由彈奏原始時間仍保留於 APP，目前輸出為 `.musicxml`。

重新建立的演奏譜使用起始拍號與高低音域分配，保留音符力度、速度及踏板；版面、歌詞與原樂器配置應使用原譜轉存保存。

## 8. 設定頁

### 外觀

- 顯示模式：系統（預設）、淺色、深色。
- 主題：薄荷綠、晴空藍、葡萄紫、莓果粉、活力橘、陽光黃。
- Hue 滑桿：0–359°；點選預設色會更新滑桿，拖動則切換為自訂色。
- 圓形色塊顯示目前顏色；外觀點擊後立即更新並保存。
- 已選模式／色彩／拍號採實心主色、高對比文字、粗體與勾選。

### 音色與音量

- Salamander 大鋼琴：預設，30 個採樣。
- VSCO 直立鋼琴：23 個採樣。
- 合成鋼琴：輕量、可立即使用。
- 鋼琴音量：0–100%，不直接控制節拍器增益。
- 音色來源與授權：顯示所選音色的作者、來源及完整條款。

音色及音量在返回主畫面後套用；載入完成後的新起音使用新採樣。

### 錄製

- BPM：20–300，輸入後按「套用速度」。
- 拍號：4/4、3/4、6/8。
- 錄製前倒數一小節、錄製時播放節拍器。

兩個核取方塊的整列保持中性背景與正常字重，只有勾選後的方框使用主題色。

## 9. 返回、背景與資料

- 設定頁左上角箭頭、Android 返回按鈕或手勢可返回主畫面。
- 切到背景會結束錄製、暫停播放並放開琴鍵，返回後自行按播放繼續。
- 目前曲目與偏好設定存在 APP 私有空間。
- 移除 APP 或清除資料會刪除私有曲目；匯出至系統檔案位置的檔案仍依其位置管理。
- 舊錄製可讀取，但舊版本未保存的原譜／表情需重新匯入原檔取得。

可先試用 [和弦與延音範例](../examples/chords-and-ties.musicxml) 或 [表情、變速與反覆範例](../examples/expression-repeat-and-tempo.musicxml)。
