# 疑難排解

## 1. APP 開啟就退出

先確認 APP 版本、手機型號與 Android 版本。Android 16 曾有視窗尚未初始化就取得全螢幕控制器的問題，0.1.1 起已修正並加入回歸測試。

連線手機後取得崩潰記錄：

```powershell
adb devices -l
adb logcat -b crash -d
```

請連同重現步驟提交 [Issue](https://github.com/mark216tw/android-minipiano-01/issues)。

## 2. 沒有聲音或音色不同

- 檢查手機媒體音量及 APP 的鋼琴音量。
- 看畫面上方的音色／載入狀態，載入中會暫用合成音色。
- 確認是否把全部自動聲部取消勾選；手動彈奏仍可發聲。
- 確認音訊輸出是否切到其他耳機／裝置。
- 若顯示音色載入失敗，可切換合成音色，再重新開啟 APP 檢查。

音色銀行只保留一套，因此切回另一套採樣可能再次載入。

## 3. 音量、延遲或破音問題

- 使用相同曲目、倍率與媒體音量比較三種音色。
- 表情記號的 p／f 會改變曲目音量，不等於音色補償失效。
- 密集和弦可能觸發限幅，實際聽感應在手機比較。
- 藍牙通常增加輸出延遲；內建喇叭與有線輸出可作比較。
- 尚未提供音訊 underrun 或端到端延遲的內建診斷頁。

## 4. 匯入失敗

| 訊息／情況 | 處理方向 |
|---|---|
| JSON 缺少 musicxml | 確認是非空字串，內容為 XML |
| score-timewise | 先以支援工具轉成 score-partwise |
| 檔案過大／ZIP 過多 | 精簡檔案至支援範圍 |
| 無有效 duration／聲部位置 | 檢查該小節 duration、backup／forward |
| 沒有可播放音符 | 確認音高、音域與支援樂器 |
| 反覆展開超限 | 檢查反覆與跳轉標記 |

「部分內容簡化」或「文字速度未自動解讀」不一定是失敗；查看摘要可了解保留／簡化的內容。完整條件見 [MusicXML 支援](MUSICXML_SUPPORT.md)。

## 5. 為什麼 ritard. 沒有漸慢？

純文字沒有唯一的起點、終點與速度幅度。本版只播放明確速度／節拍器數值，不猜測文字變速；原譜轉存仍保留文字。

## 6. 聲部、原譜或新記號沒有出現

舊版本沒有保存完整原譜或聲部資料，更新後仍能讀舊演奏，但不會自動重建遺失資訊。重新匯入原始檔即可取得新模型與原譜轉存功能。

## 7. 曲目被取代或消失

- 匯入與完成錄製會新增到音譜庫；請開啟音譜庫查找其他曲目。取消倒數或沒有音符的錄製不新增。
- 清除資料或移除 APP 會刪除私有保存檔。
- 若已匯出，可從系統檔案位置重新匯入。
- 開啟原譜轉存與演奏資料匯出前，確認目前曲目及模式。

## 8. 建置失敗

- `SDK location not found`：設定 ANDROID_HOME 或 local.properties。
- Android SDK 36 未安裝：安裝相應 Platform／Build Tools。
- Robolectric SDK 36 要求 Java 21：指定 `testJavaHome` 或使用相容的建置 JVM。
- Gradle 無法於較新 JDK 執行：建置 JVM 回到相容的 JDK 17／21，測試 JVM另行指定。
- Python 套件缺少：依 [建置指南](BUILD_AND_TEST.md) 安裝音色工具相依套件。

記錄完整錯誤輸出，有助區分建置、解析與音訊問題。
